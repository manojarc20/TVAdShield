# TVAdShield

Open-source system-wide ad and tracker filtering research project for Android/Google TV.

Safety first: this project is designed as a normal Android TV app. It will not root the TV, unlock the bootloader, flash firmware, modify system partitions, or replace Google TV components.

## Development plan
Build locally -> automated tests -> release candidate -> TV installation -> real-world testing -> fixes -> V2.

Network filtering cannot guarantee removal of every ad, especially server-side or DRM-integrated ads. Claims will be based on measured tests.
